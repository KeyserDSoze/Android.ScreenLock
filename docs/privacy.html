Screen Lock

Privacy Policy · Last updated 1 October 2026

Screen Lock is developed and published by Alessandro Rapiti.

The Google Play version requires no account and does not collect, sell, share, or use personal data for advertising, analytics, profiling, or tracking.

Data collection

The Google Play build does not collect or share personal data and does not read the content displayed by Telegram or other apps.

Network access

The Google Play build does not include the GitHub self-updater and does not request Internet access. The separately distributed GitHub APK can use Internet access only to check and download official releases from the public GitHub Releases service.

Permissions and special access

Screen Lock can request Android's Display over other apps special access for its core function: placing a touch-blocking overlay above the currently visible call or app. The overlay receives touches but does not inspect the content underneath it.

The Google Play build does not include an Accessibility Service. A foreground service may run while a user-activated touch lock is arming or active, with a persistent notification.

Local settings

Settings such as unlock duration, target size and position, language, haptics, and dimming are stored locally on the device.

Advertising and analytics

Screen Lock contains no advertising SDK, analytics SDK, or tracking service.

Contact

For privacy questions or issues, use the public project issue tracker: github.com/KeyserDSoze/Android.ScreenLock/issues.
